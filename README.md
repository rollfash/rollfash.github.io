# עברדל 🟩

משחק ניחוש מילים יומי בעברית. מילה חדשה בת חמש אותיות בכל יום, שש הזדמנויות לנחש.

אתר סטטי לגמרי — HTML, CSS ו‑JavaScript בלבד. אין שרת, אין תלויות, אין שלב בנייה.
מתאים לאירוח ישיר ב‑GitHub Pages.

> שם המשחק מוגדר במקום אחד: [`js/config.js`](js/config.js).
> שינוי `APP_NAME` שם מעדכן את הכותרת, לשונית הדפדפן וטקסט השיתוף.
> חלופות אם "עברדל" לא מוצא חן: `חמילה`, `תן מילה`, `בול פגיעה`.

## איך זה עובד

מילת היום **אינה** נשלפת משרת. היא נגזרת מהתאריך:

1. מאגר התשובות מעורבב בערבוב דטרמיניסטי עם זרע קבוע, כך שסדר המילים
   אינו סדר הרשימה — אבל זהה אצל כל השחקנים.
2. מחושב מספר הימים שחלפו מאז `EPOCH`, לפי השעון המקומי.
3. אם התאריך מופיע ב‑[`js/schedule.js`](js/schedule.js) — נלקחת המילה שנקבעה לו.
   אחרת נבחרת המילה לפי האינדקס.

לכן כל השחקנים מקבלים את אותה מילה באותו יום, בלי שום קוד צד־שרת.
המילה מתחלפת בחצות לפי השעון המקומי של השחקן.

### אותיות סופיות

המקלדת כוללת 22 אותיות בלבד. כל המילים מנורמלות (ך→כ, ם→מ, ן→נ, ף→פ, ץ→צ),
והצורה הסופית מוצגת אוטומטית באות האחרונה. השחקן תמיד מקיש על האות הרגילה.

סדר המקשים זהה למקלדת עברית פיזית — `ק` בצד שמאל, `פ` בצד ימין.

## המילון

| | |
| --- | --- |
| מילות תשובה (יכולות לצאת כמילת היום) | **2,647** — כ‑7.3 שנות משחק |
| סך המילון (מילים חוקיות לניחוש) | **62,517** |

ההפרדה מכוונת: מאגר הניחושים כולל גם הטיות פועל נדירות כמו `תתרפס`, כדי
שכמעט כל מילה עברית בת חמש אותיות תתקבל. מילת היום נבחרת רק ממאגר מצומצם
ונקי יותר.

המילון נבנה מקבצי המקור שבתיקיית `data/`:

```bash
node tools/build-words.js
```

הסקריפט קורא כל קובץ ששמו מתחיל ב‑`source-`, שולף ממנו כל רצף של חמש אותיות
עבריות שעומד בפני עצמו, ומייצר את [`js/words.js`](js/words.js). הפורמט של קובץ
המקור לא משנה — טקסט, מערך JS או מחרוזת מופרדת ברווחים — אפשר פשוט לזרוק
עוד קובץ לתיקייה ולהריץ מחדש.

| קובץ ב‑`data/` | תפקיד |
| --- | --- |
| `source-*.txt` / `source-*.js` | מקורות מילים |
| `exclude-from-answers.txt` | לא תהיה מילת היום, אך חוקית לניחוש |
| `blocklist.txt` | נפסלת מהמילון כולו |

רק חלק מהמקורות תורמים למאגר התשובות — הרשימה מוגדרת ב‑`ANSWER_SOURCES`
בתוך [`tools/build-words.js`](tools/build-words.js).

> **רוצים מילות יום נפוצות יותר?** הסירו את `'source-nouns.txt'` מ‑`ANSWER_SOURCES`.
> מאגר התשובות יקטן לכ‑850 מילים מוכרות (כ‑2.3 שנים), במקום 2,647 שכוללות
> גם מילים נדירות יחסית כמו `הגמון` או `אוגדן`.

## ממשק הניהול

פותחים את `admin.html`. אפשר להוסיף ולהסיר מילים, לבדוק אם מילה קיימת,
ולקבוע מראש את המילה של תאריך מסוים.

הממשק עובד בשני מצבים:

**מקומי** — כשמריצים `node tools/serve.js`. השמירה כותבת ישירות לקבצים
ומריצה מחדש את בניית המילון. זה המצב הנוח.

```bash
node tools/serve.js
```

המשחק: <http://localhost:8080> · הניהול: <http://localhost:8080/admin.html>

**סטטי** — כשהעמוד מתארח ב‑GitHub Pages. דף באתר סטטי אינו יכול לשנות את
האתר שממנו נטען, ולכן השמירה מורידה את הקבצים המעודכנים; מחליפים אותם
במאגר, מריצים `node tools/build-words.js` אם נגעתם במילים, ועושים `git push`.

### קביעת מילה לתאריך

בממשק הניהול, תחת **מילה מתוזמנת** — בוחרים תאריך (ברירת המחדל היא מחר),
מקלידים מילה ולוחצים **קביעה**. תאריך שלא נקבעה לו מילה מקבל מילה
אוטומטית. הרשימה של 14 הימים הקרובים מראה בדיוק מה יֵצא בכל יום.

הממשק יזהיר אם המילה שנקבעה אינה במילון — במקרה כזה שחקנים לא יוכלו
להקליד אותה, והמשחק יהיה בלתי אפשרי.

### למה הוספת מילים משנה את מילת היום

הערבוב מתבצע על כל מאגר התשובות, ולכן הוספה או הסרה של מילה מזיזה את כל
הסדר — כולל היום הנוכחי. שני מנגנונים מונעים מזה לפגוע בשחקנים:

- ממשק הניהול **מקבע אוטומטית** את מילת היום ב‑`schedule.js` לפני שמירת
  שינויים במאגר, כך שהיום הנוכחי לא זז.
- משחק שכבר התחיל ממשיך עם המילה שאיתה התחיל, גם אם המילון התעדכן מאז.

ימים עתידיים שלא קובעו כן ישתנו. זה בדרך כלל בסדר, אבל אם תזמנתם מילה
לתאריך מסוים — היא תישאר כפי שנקבעה.

## אירוח ב‑GitHub Pages

1. ליצור מאגר חדש ב‑GitHub (למשל `wordle`).
2. לחבר ולהעלות:

```bash
git remote add origin https://github.com/USERNAME/wordle.git
git push -u origin main
```

3. במאגר: **Settings → Pages**, ותחת *Build and deployment* לבחור
   **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`. לשמור.

תוך דקה או שתיים האתר יהיה זמין בכתובת `https://USERNAME.github.io/wordle/`,
וממשק הניהול ב‑`/admin.html`. כל `git push` לענף `main` מעדכן את האתר.

> `admin.html` אינו מוגן בסיסמה — אין שרת שיאמת אותה. הוא גם אינו מסוכן:
> הוא רק מוריד קבצים אצל מי שפתח אותו. עדיין, הוא חושף את המילים הקרובות,
> אז אם זה מפריע — אל תעלו אותו, והשתמשו בו רק מקומית.

```
js/schedule.js        מילים שנקבעו לתאריכים מסוימים
js/daily.js           בחירת מילת היום (משותף למשחק ולניהול)
js/game.js            לוגיקת המשחק

tools/build-words.js  בניית המילון מקבצי data/

data/                 קבצי המקור של המילים
```

## מה נשמר במחשב של השחקן

הכול ב‑`localStorage` בלבד — שום מידע לא נשלח לשום מקום:

| מפתח | תוכן |
| --- | --- |
| `he-wordle:daily` | הניחושים של היום ומילת היום שאיתה התחיל |
| `he-wordle:stats` | סטטיסטיקות מצטברות ורצפים |
| `he-wordle:theme` | מצב כהה או בהיר |
| `he-wordle:free` | האם "מצב חופשי" פעיל |

## הערות

- **מצב חופשי** (בחלון ההסבר) מאפשר לנחש כל צירוף של חמש אותיות, גם אם אינו במילון.
- האובייקט `window.__wordle` נחשף לצורכי בדיקה וניפוי שגיאות, וכולל את פתרון היום.
  זה לא פוגם באבטחה — המילון ואופן הבחירה ממילא נמצאים בקוד הצד־לקוח, בדיוק כמו
  במשחק המקורי.
