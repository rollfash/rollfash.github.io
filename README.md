# וורדל בעברית 🟩

משחק ניחוש מילים יומי בעברית. מילה חדשה בת חמש אותיות בכל יום, שש הזדמנויות לנחש.

אתר סטטי לגמרי — HTML, CSS ו‑JavaScript בלבד. אין שרת, אין תלויות, אין שלב בנייה.
מתאים לאירוח ישיר ב‑GitHub Pages.

## איך זה עובד

מילת היום **אינה** נשלפת משרת. היא נגזרת מהתאריך:

1. רשימת המילים מעורבבת בערבוב דטרמיניסטי עם זרע קבוע (`mulberry32(20260101)`),
   כך שסדר המילים אינו סדר הרשימה — אבל זהה אצל כל השחקנים.
2. מחושב מספר הימים שחלפו מאז `EPOCH` (1 בינואר 2026), לפי השעון המקומי.
3. המילה נבחרת לפי האינדקס הזה.

לכן כל השחקנים מקבלים את אותה מילה באותו יום, בלי שום קוד צד־שרת.
המילה מתחלפת בחצות לפי השעון המקומי של השחקן.

עם 298 מילות תשובה, המשחק רץ כ‑10 חודשים לפני שמילה חוזרת.

### אותיות סופיות

המקלדת כוללת 22 אותיות בלבד. כל המילים מנורמלות (ך→כ, ם→מ, ן→נ, ף→פ, ץ→צ),
והצורה הסופית מוצגת אוטומטית באות האחרונה. השחקן תמיד מקיש על האות הרגילה.

## הרצה מקומית

```bash
node tools/serve.js
```

ואז לפתוח <http://localhost:8080>.

אפשר גם לפתוח את `index.html` ישירות בדפדפן — הכול עובד מ‑`file://`.

## אירוח ב‑GitHub Pages

1. ליצור מאגר חדש ב‑GitHub (למשל `wordle`).
2. לחבר ולהעלות:

```bash
git remote add origin https://github.com/USERNAME/wordle.git
git branch -M main
git push -u origin main
```

3. במאגר: **Settings → Pages**, ותחת *Build and deployment* לבחור
   **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`. לשמור.

תוך דקה או שתיים האתר יהיה זמין בכתובת `https://USERNAME.github.io/wordle/`.

כל `git push` לענף `main` מעדכן את האתר אוטומטית.

## הוספת מילים

עורכים את [`js/words.js`](js/words.js):

- `ANSWERS` — מילים שיכולות להיות מילת היום.
- `EXTRA` — מילים תקינות שמותר לנחש, אך לא יהיו מילת היום.

אחרי כל עריכה כדאי להריץ את הבדיקה:

```bash
node tools/check-words.js
```

היא מוודאת שכל מילה באורך חמש אותיות עבריות, שאין אות סופית באמצע מילה,
ושאין כפילויות.

> ⚠️ הוספה או הסרה של מילים ב‑`ANSWERS` משנה את הערבוב, ולכן משנה את
> מילת היום מהיום הנוכחי והלאה. זה לא משפיע על משחקים שכבר הסתיימו.

## מה נשמר במחשב של השחקן

הכול ב‑`localStorage` בלבד — שום מידע לא נשלח לשום מקום:

| מפתח | תוכן |
| --- | --- |
| `he-wordle:daily` | הניחושים של היום הנוכחי |
| `he-wordle:stats` | סטטיסטיקות מצטברות ורצפים |
| `he-wordle:theme` | מצב כהה או בהיר |
| `he-wordle:free` | האם "מצב חופשי" פעיל |

## הערות

- **מצב חופשי** (בחלון ההסבר) מאפשר לנחש כל צירוף של חמש אותיות, גם אם אינו במילון.
- האובייקט `window.__wordle` נחשף לצורכי בדיקה וניפוי שגיאות, וכולל את פתרון היום.
  זה לא פוגם באבטחה — המילון ואופן הבחירה ממילא נמצאים בקוד הצד־לקוח, בדיוק כמו
  במשחק המקורי. מי שרוצה להציץ, יכול.
