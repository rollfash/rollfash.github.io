# עברדל 🟩

משחק ניחוש מילים יומי בעברית. מילה חדשה בת חמש אותיות בכל יום, שש הזדמנויות לנחש.

### ▶ [שחקו כאן](https://rollfash.github.io/wordle/)

---

מילה אחת ליום, זהה לכל השחקנים, מתחלפת בחצות. מילון של יותר מ‑62,000 מילים
עבריות, מקלדת בסדר של מקלדת עברית רגילה, ותמיכה באותיות סופיות — פשוט
מקישים על האות הרגילה.

עובד בדפדפן בלבד: אין שרת, אין הרשמה, ושום דבר לא נשמר מחוץ למכשיר שלכם.
